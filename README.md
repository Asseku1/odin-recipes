# odin-recipes
First "Official Project" from the Odin Project including basics of HTML 

This is repo includes my solution to the "Project: Recipes" from Odin Project. 

It is created with the help of Visual Studio Code (VSCODE) with  use of AI agents to generate descriptions for the individual recipes of the dishes

For this project I've used images that include Free to Use and Share License

I've mostly used <ul> and <ol> for the Recipes

I made sure to add a feature to return to Homepage wit Recipe Indexes  on each Recipe site so the user doesn't have to re enter the site via original link
